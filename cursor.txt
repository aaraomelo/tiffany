0. A LEI — a construção que fundamenta a migração
==================================================
papers/racionais.tex fecha a construção Z → Q pelo molde dual:

    Z² ⊃ V_rat → V_rat/∼ ≅ Q      (a,b)∼(c,d) ⟺ ad=bc

O racional é a CLASSE DE EQUIVALÊNCIA de pares de inteiros. A involução é o
swap ι(a,b)=(b,a), que induz x⁻¹ no quociente (Thm swap-inverso). As
operações são inteiras no representante:

    soma:     (a,b)⊕(c,d) = (ad+bc, bd)
    produto:  (a,b)⊗(c,d) = (ac, bd)
    oposto:   −(a,b)       = (−a, b)
    inverso:  (a,b)⁻¹      = (b, a)       a≠0

A equivalência é decidida por dois produtos inteiros, sem divisão:
    Cruz(a,b,c,d) = ad−bc = 0  ⟺  [(a,b)] = [(c,d)]
    Cruz < 0  ⟺  a/b < c/d   (b,d>0)

Dir = ad+bc e Cruz = ad−bc são os numeradores inteiros das leituras simétrica
e antissimétrica sobre o denominador comum bd, com B((a,b),(c,d))=ad escolhida.

O swap NÃO preserva V_rat (ι(0,b)=(b,0)), mas preserva V× = {(a,b):ab≠0}.
A extensão a P¹(Q) (incluindo [1:0]=∞) é interface herdada da torre, não
construção deste degrau.

Conjugação de campo (a+b√D ↦ a−b√D) tem Fix=Q.
Dobra s†=−1/s tem Fix={s:s²=−1}. NÃO confundir.


1. ARQUITECTURA DE 16 BITS — o alvo
====================================
O envelope computacional (racionais.tex §sec:ja):

    E₁₆ = {(p,q) ∈ Z² : −32768 ≤ p ≤ 32767, 1 ≤ q ≤ 32767, gcd(|p|,q)=1}

    typedef struct { int16_t p, q; } Qz;    /* p/q em par de 16 bits, q≠0 */

E₁₆ NÃO é Q, nem subcorpo finito. É um envelope de representantes canónicos.
Cada operação retorna elemento de E₁₆ ou sinaliza saturação (qz_saturou).
red(0,b) = (0,1) para todo b≠0.

Produto exacto em pares de 16 bits (lib/dual16.h):

    typedef struct { uint16_t alto, baixo; } D32;

O par (alto,baixo) representa exactamente os 32 bits do resultado em
complemento de dois. A interpretação assinada ocorre após recomposição.
Comparação: alto (signed 16) primeiro; em igualdade, baixo (unsigned).

    d16_mult(a,b) → D32           produto 16×16 → par de 16
    d16_cmp_prod(a,b,c,d) → int   sinal(ab−cd) sem materializar Qz

Todas as operações: pares com pares resultam em pares. Os produtos
intermediários usam largura dupla (D32), reduzidos depois ao domínio E₁₆.
